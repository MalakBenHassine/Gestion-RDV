# Gestion-RDV

Appointment management application built with Node.js, Express, and EJS templates.

## Features

- Appointment creation and scheduling
- Controller / model / route structure (MVC-style)
- Server-rendered views with EJS

## Stack

Node.js, Express, EJS

## Project structure

```
Gestion-RDV/
├── Controller/   # Request handlers
├── models/       # Data models
├── routes/       # Express routes
├── middlewares/  # Express middlewares
├── views/        # EJS templates
├── css/          # Stylesheets
└── server.js     # App entry point
```

## Getting started

```bash
git clone https://github.com/MalakBenHassine/Gestion-RDV.git
cd Gestion-RDV
npm install
node server.js
```
